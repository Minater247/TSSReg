# Privacy Policy

Last updated: 13 November 2026

## Data Collection

TSSReg sends requests only to UC San Diego’s official Triton Student System (TSS) at `https://tss.ucsd.edu`. These requests use your existing TSS session to retrieve information for the extension’s features. The extension sends no data to the developer or to any other service and collects no analytics or telemetry.

## Information Read

TSSReg runs only on `https://tss.ucsd.edu`. On affected pages the extension uses existing data TSS has already loaded into the page, and - where applicable - data loaded from TSS API calls copied verbatim from the existing site code.

Fields include:
- Course information
- Enrollment status
- Course schedule
- Appointment times and information

TSSReg uses this information in your browser to display calendars, enrollment information, and course filters. The extension retains only the planner data described below after you close the tab.

## Data Stored

TSSReg saves your planned schedules and custom events in your browser’s local storage for `tss.ucsd.edu`. This data stays in your browser. It includes:

- Course codes
- Course meeting times
- Custom scheduled events

These are deleted when you clear the site's data.

## Permissions

- **Host access to `https://tss.ucsd.edu`** is what lets the extension modify TSS pages and read the TSS APIs on your behalf.
- **`declarativeNetRequestWithHostAccess`** allows `https://tss.ucsd.edu` to redirect to `https://tss.ucsd.edu/fiori`. It reads no request contents and applies to no other URL.

## Chrome Web Store Limited Use

TSSReg uses student data only to provide its features on TSS. TSSReg’s use of this data adheres to the Chrome Web Store User Data Policy, including its [Limited Use requirements](https://developer.chrome.com/docs/webstore/program-policies/limited-use).
